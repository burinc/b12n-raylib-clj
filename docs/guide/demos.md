# Full-size demo gallery

Every example at full size, linked from
[the example catalog](example-catalog.md)'s preview thumbnails.
Every GIF here is committed. They are regenerated by `bb record`, a
maintainer-only task driving a screen-capture tool that is not publicly
released; the per-example capture settings and input timelines live in
[`scripts/demo_manifest.edn`](../../scripts/demo_manifest.edn).
